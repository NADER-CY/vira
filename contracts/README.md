# Contracts

| File | What | Source of truth |
|---|---|---|
| `openapi/public.v1.json` | Public API (mobile + seller web) | generated by `scripts/gen_openapi.py` |
| `openapi/admin.v1.json` | Super Admin API | generated by `scripts/gen_openapi.py` |
| `events/envelope.v1.schema.json` | Outbox / NATS event envelope (CloudEvents 1.0 compatible) | hand-written |

Rules (doc 07):

* URI major versioning (`/v1`); only additive changes inside a version.
* Errors are RFC 9457 `application/problem+json` with a stable `code`.
* Event types are `vira.<module>.<event>.v<N>`; breaking changes publish `v<N+1>` alongside `v<N>`.

CI checks:

1. `python3 scripts/gen_openapi.py --check` — generated JSON is up to date.
2. `npx @redocly/cli lint` — the documents are valid OpenAPI 3.1.
3. `backend/internal/app/contract_test.go` — every route served by the Go routers is in the contract and vice versa,
   and the error-code enum equals the codes the backend can return.
4. Web apps generate TypeScript types from these files (`openapi-typescript`).
